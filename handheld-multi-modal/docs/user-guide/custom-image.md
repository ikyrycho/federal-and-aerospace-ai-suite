# Custom image

This documentation covers how to build customized image of Ubuntu that allows deployment at scale. It is different from [Instalation on Ubuntu](installation-on-ubuntu.md), which uses default or existing Ubuntu operating system.
It needs additional system, called `Developer system`, which is covered in [System Requirements](./infrastructure/system-requirements.md).
